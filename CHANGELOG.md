# Changelog

## 1.0.0 - 2026-10-28

- Initial native Rust implementation with macroquad UI and independent game
  rules.
- Seven-bag pieces, SRS transition kick data, hold, previews, line clears,
  scoring and six mode choices.
- CPAL audio callback driven by the supplied Dollchan bytebeat formula and
  standalone WAV diagnostic.
- Versioned TOML profile persistence, records, initial documentation and CI.

This is an initial implementation, not a claim of full release readiness;
remaining work is tracked in `docs/IMPLEMENTATION_STATUS.md`.
